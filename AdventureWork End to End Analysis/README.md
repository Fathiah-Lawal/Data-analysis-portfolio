# Sales Performance Analysis

## Overview
This project involves analyzing sales data to identify key trends and insights across customers, products, and territories. The main goal is to support decision-making for sales strategies and revenue optimization.

## Analysis Summary
- **Top Products by Revenue & Profit:** Highlighted products generating the highest revenue and/or profit margins.  
- **Customer Segmentation:** Categorized customers as store or individual and analyzed lifetime value and order frequency.  
- **Territory Performance:** Examined sales distribution and growth trends across territories.  
- **Sales Trends:** Evaluated monthly and yearly sales patterns to identify growth opportunities.  

## Tools & Technologies
- SQL for data extraction  
- Excel for intermediate analysis and reporting
