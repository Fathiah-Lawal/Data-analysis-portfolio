## Sales Performance Analysis Dashboard

### Overview

This project presents an interactive Sales Performance Dashboard built using the Global Superstore dataset. The goal of the dashboard is to help users understand business performance across revenue, profit, segment behavior, shipping cost, returned sales, and product-level trends. The dashboard consolidates the most important KPIs into a single view to support data-driven decision making.

---

## Insights Summary

1. The **Consumer segment** generates the highest revenue and profit overall, followed by Corporate.
2. Some segments and ship modes show losses when returns occur, which indicates areas needing workflow improvement.
3. Revenue shows noticeable fluctuations across months, suggesting seasonal buying behavior.
4. Profit varies significantly by product category, with some categories showing strong performance while others are weak or negative.
5. The South and EMEA regions often show strong contributions depending on filter selection.
